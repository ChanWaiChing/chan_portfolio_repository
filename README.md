# 大穂兄弟 / BROTHERS

「兄弟の力で、アイデアをカタチに。」をテーマにした、日本語のポートフォリオサイトです。

## 技術スタック

- Next.js 16.4.3 / App Router
- React 19.3.1 / TypeScript
- 4つのサービスを切り替える、アクセシブルなヒーローカルーセル
- CSSアニメーション / Lucideアイコン
- Noto Sans JP / DM Sans（ローカル配信。Google Fontsへの接続不要）
- Playwright（PC / モバイルの操作テスト）

Node.js 20.9以上が必要です。この環境ではNode.js 24で検証しました。

## 起動

```bash
cd /workspace/chan_portfolio_repository
npm ci
npm run dev
```

開発サーバーはポート3000を使用します。本番相当の確認は次の通りです。

```bash
npm run build
npm run start
```

## 実装内容

- プロフィール、対応業務、制作コンセプト、制作方針、FAQ、お問い合わせ
- オリジナルの3D風ロボット画像と、小さなアニメーション付きボット
- タブ付きヒーロー（8秒ごとの自動切り替え、停止・再生、矢印キー・Home・Endに対応）
- 光沢のあるCTA、サービス別の入口カード、白とブルーを基調にしたセクション
- スキルの無限マーキー（ホバー時に停止）
- 制作コンセプトの詳細ダイアログとFAQアコーディオン
- 相談メモの作成、クリップボードへのコピー、内容を引き継いだメール作成
- モバイルメニュー、キーボード操作、フォーカス制御、動きを抑える設定への対応
- 動きを抑える設定ではヒーローを手動切り替え。タブの操作・フォーカス時も自動切り替えを停止

掲載した制作例は自主制作コンセプトであり、クライアント実績ではありません。プロフィール内容は提供された情報をもとに構成しています。

## 検証

```bash
npm run typecheck
npm run build
npm run test:e2e
```

ブラウザテストは、本番ビルドを用意してから実行してください。テスト実行時にサーバーを自動起動します。クラウド環境に既存の `/usr/bin/chromium` を使用します。別の環境では `CHROMIUM_PATH` にChromiumの実行ファイルパスを指定してください。

検証範囲：プロフィール表示、モバイルナビゲーション、横スクロールの発生確認、ヒーロータブとキーボード操作、問い合わせ先、制作コンセプトの詳細、FAQ、相談内容のメール引き継ぎ、Escapeで閉じる操作、reduced-motion、ブラウザ実行時エラー。

## デザインについて

参考サイト https://webmarks.co.jp/ の現行UIをもとに、白・淡いブルー・ネイビーの配色、2段のヘッダー、光沢のあるCTA、タブ付きヒーロー、3列の入口カードへ刷新しました。大穂兄弟のコンテンツ・問い合わせ先・オリジナルのロボット画像を使用しています。

画像はこのサイト向けに生成したイメージであり、本人・クライアント・実際の職場の写真ではありません。Webmarksのロゴやマスコットを転載していません。

配色とレイアウトの調整は `app/webmarks-theme.css`、既存コンポーネントの基礎スタイルは `app/globals.css` と `app/reference-theme.css`、画像は `public/images/` です。ヒーローは画面幅に合わせてレイアウトが変わります。

WindowsのPowerShellでnpm.ps1が制限される場合は、セキュリティ設定を変更せず次のコマンドを使えます。

```powershell
npm.cmd ci
npm.cmd run dev
```
