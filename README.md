# 大穂兄弟 / OHO BROTHERS

日本語の制作ポートフォリオ。Next.js 16.4.3 / React 19.3.1 / TypeScript。

ブランドの約束・キャラクターの役割・公開前に必要な実情報は [ブランド運用ガイド](docs/brand-guide.md) にまとめています。

## 開発とプレビュー

```powershell
npm.cmd ci
npm.cmd run dev -- --port 3001
npm.cmd run typecheck
npm.cmd run build
npm.cmd run start -- --port 3001
```

プレビューは http://localhost:3001 。開発サーバーと本番サーバーを同時に同じポートで起動しないでください。ビルド時は開発サーバーを止め、本番確認用に起動し直してください。

## ページとデザイン

1. 「デザインと開発を、ひとつのチームで。」の約束と、4秒で切り替わるブランドシーン。
2. 商品絞り込み・タスク管理・日記追加を試せる3つの自主制作デモ、兄弟のストーリーとプロフィール。
3. Webサイト・業務システム・継続改善の3つの入口。対応領域・ワークフロー・技術リングは展開して確認。
4. 相談から引き継ぎまでの4段階と、各段階で確認すること。
5. 20件の仮パッケージ。カテゴリ絞り込み・6件ずつのページ切り替え・詳細。
6. 30件の架空ポートフォリオ。検索・カテゴリ・9件ずつのページ切り替え・コンセプト詳細。
7. 8つのFAQとボットガイド。
8. 連絡先とフォーム。PCは横並び、760px以下は縦並び。
9. ダークネイビーのフッター。縦書きの屋号、用途がわかるリンク、ページ先頭への操作。

色・文字・余白・カード・ボタンは **`app/site.css` の1か所**で管理します。旧テーマ10枚の重複ルールと未使用セレクタは削除しました。クールなライトグレー、白いカード、スレートの本文、インディゴの案内・相談ボタン、ダークネイビーのフッターを組み合わせています。画像は元の彩度を保ち、ホバーは赤・橙・黄・緑・青・藍・紫の鮮やかな7色グローを使用します。`--paper`、`--surface`、`--ink`、`--muted`、`--accent`、`--cta` が配色の共通トークンです。Noto Sans JPとDM Sansはローカル配信です。

パッケージ・制作例・サービス・ワークフローの7色グローは、ホバーとキーボードフォーカスで鮮やかに発光します。タッチ端末でホバーが残る影響を抑え、reduced-motionでは回転・光・切り替えアニメーションを止めます。ヒーローとスキルリングは画面外で停止します。

主なファイル：

- `components/portfolio.tsx`：ページ構成、ナビゲーション、検索・フィルタ・ページ切り替え、詳細ダイアログ。
- `components/hero-showcase.tsx`：固定H1、4秒のブランドシーン切り替え、停止・再生、矢印・Home・End操作。AOとIROのキャラクターとHTMLで描く図解です。
- `components/brand-story.tsx`：兄弟のストーリー、3つのサービス入口、4段階の進め方、問い合わせ後の案内。
- `components/concept-demo.tsx`：mori. / flow / 日々、の操作できるデモ。画面内の状態のみ使用し、保存しません。
- `components/brother-introductions.tsx`：専門性、経験、ボットの吹き出し。
- `components/skill-workflows.tsx`：ワークフローカードと80秒周期のリング。バッジは略号ではなく技術名を表示し、静的な技術一覧も併記。
- `components/faq-section.tsx`：短い質問と回答。送信方式に応じて説明が変わります。
- `components/contact-methods.tsx`：窓口別のカラーアイコンとコピー。コピー状態は3秒後に解除。
- `components/contact-form.tsx`：入力検証、送信・確認・コピー、エラー時の入力保持。
- `components/pattern-footer.tsx`：屋号とラベル付きのリンク。
- `lib/catalog.ts`：サンプルデータ、制作コンセプトの課題・設計方針・検証内容。
- `lib/site.ts`：公開連絡先と差し替え用の案内画像。
- `app/opengraph-image.tsx`：1200×630の共有画像。

表示件数とページ数はデータから計算します。フィルタ・検索・ページはURLの `package`、`work`、`q`、`pp`、`wp` に保存され、再読み込み後も復元します。メニューとダイアログはフォーカスを管理し、背景をinertにし、Escapeで閉じられます。

レート制限はインスタンス内でメールアドレスごとに10分5回です。複数インスタンスで公開する場合はホスティング側のWAF・共有レート制限も設定してください。本文・メールアドレスはアプリのログやDBに保存しません。送信プロバイダ側の保管設定は別途管理します。実装は[Resend公式API](https://resend.com/docs/api-reference/emails/send-email)を参照しています。

公開ドメインは `NEXT_PUBLIC_SITE_URL` で指定します。未設定時の共有画像URLはローカルプレビュー向けです。外部サービス設定や本物の納品実績は、見た目の調整だけで確定できないため、未設定・サンプルであることを明示しています。

## データと画像の差し替え

パッケージの費用・期間は表示例です。制作例は架空の自主制作コンセプトで、実在顧客・納品・成果数値を示しません。実際のデータがそろったら `lib/catalog.ts` のレコードを更新してください。

現在の連絡先案内は、TOMOのキャラクターを使ったHTMLです。過去の差し替え用画像 `public/images/contact-placeholder.webp` と設定は保管しています。

現在のヒーローとプロフィールは、ボットとHTMLで構成しています。人物がスタッフ本人に見える誤解を避けるため、過去の生成人物画像は表示しません。以下の元画像は `public/images/heroes/` に保管しています。

- `ai-first-view.webp`：ユーザーアップロード原画（1774×887、可逆WebP）。男性2人と2体のボット。
- `brothers-natural.webp`：男性2人と2体。
- `couple-one-natural.webp`：最初のカップルと2体。
- `couple-two-natural.webp`：別のカップルと2体。

現在のブランドシーンは、デスクトップ420px・モバイル340pxの固定高です。メッセージと工程はHTMLで表示し、画像内の小さな文字に依存しません。

`-natural`画像はImageGenで、MacBook・iPhone・自然なスタジオ・異なるボットの作業を描いた制作イメージです。服飾ブランドとの提携を示しません。生成・編集プロンプトは同フォルダの `prompts.json` と `natural-prompts.json` に残しています。元画像も保存しています。

`public/images/bots/` の `sunset`、`peach`、`ocean`、`mint` は、アップロードされた4モデルをもとに背景を透過したWebPです。ImageGenでデザイン・色・髪形・表情・ポーズを維持し、チェッカー背景とUIマークを除去しました。装飾ボットは読み上げと操作を妨げません。プロフィール・技術紹介・強み・FAQ・フッターで案内役として使い、異なる旧ボット画像は表示しません。

デザインはアップロード資料、[WEBMARKS](https://webmarks.co.jp/)、[Yoom](https://lp.yoom.fun/)、[AI Shift](https://aishift.com/)を参考に、独自のコンテンツとして構成しています。参考サイトのロゴ・顧客写真・マスコットは使用していません。

## ブラウザ検証

```powershell
npm.cmd run test:e2e
node scripts/capture-review.cjs
```

PlaywrightはPC（1440×1000）とモバイル（iPhone 13相当）で確認します。Windowsではインストール済みChromeを自動選択します。他環境ではPlaywrightのブラウザ、または `CHROMIUM_PATH` を指定してください。ベースURLは `http://localhost:3001`、変更時は `PLAYWRIGHT_BASE_URL` を指定します。この環境では127.0.0.1経由で開発用接続が正常に動かないため、表示されたlocalhostのURLを使います。

画面キャプチャは `test-results/review/`（Git対象外）。ナビゲーション、全20/30件への到達、詳細・相談、FAQ、フォーム、コピー、4秒の切り替え、キーボード、reduced-motion、URL復元をテストします。直接送信のテストはプロバイダAPIをモックし、実メールを送信しません。
