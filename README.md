# 大穂兄弟 / BROTHERS

「兄弟の力で、アイデアをカタチに。」をテーマにした日本語のポートフォリオサイト。
Next.js 16.4.3 / React 19.3.1 / TypeScript。Noto Sans JP・DM Sansはローカル配信です。

## ページ構成

1. Introduction：4秒ごとに切り替わる4枚の自然なスタジオのヒーロー、兄弟の紹介
2. サービス・スキル：4つの対応領域、3枚のワークフロー図解カード、ツールが回るスキル紹介
3. 私たちの強み：課題に応える3つの特徴
4. サービスパッケージ：20件のサンプル、カテゴリ絞り込み、6件ずつのページ切り替え、詳細ダイアログ
5. ポートフォリオ：30件の架空コンセプト、カテゴリ・キーワード検索、9件ずつのページ切り替え、詳細ダイアログ
6. FAQ：アコーディオン
7. お問い合わせ：入力検証、確認、メールアプリへの引き継ぎ、コピー
8. フッター：クリーム色の有機的な柄、縦書きの屋号、丸いリンク、ピル型のセクションナビゲーション

アップロードされた参考画像の白・淡いブルー、角丸カード、ブルーの見出し、青・オレンジのCTAをもとに構成しています。参考サイトのロゴ、マスコット、クライアント写真は使用していません。

## サンプルを実際のコンテンツに差し替える

`lib/catalog.ts` がカタログのデータです。

- `packageSeeds`：パッケージのタイトル、カテゴリ、説明、成果物
- `servicePackages`：ID、表示金額、期間を含む20件のデータ
- `workSeeds`：架空ブランド、タイトル、カテゴリ
- `portfolioItems`：ID、説明、技術、サムネイルの種類・配色を含む30件のデータ

追加や変更は同じ型のレコードで行えます。件数表示・カテゴリ絞り込み・ページ数はデータから計算します。各セクションの「全20」「全30」、サンプルの説明文は、正式公開に合わせて本文と一緒に更新してください。

金額・期間・内容は仮の表示例であり、実際の見積もりではありません。ポートフォリオは実在する顧客や納品実績ではありません。画像も制作イメージです。

## お問い合わせ

連絡先の案内パネルを上、フォームを下にした縦並びです。案内パネルの画像は `lib/site.ts` の `contactImage`（src・width・height・alt）で指定できます。お問い合わせとフッターのリンクアイコンは、役割別に色分けしています。レイアウトは `app/contact-layout.css` です。

現在は仮の画像 `public/images/contact-placeholder.webp`（1920×640）を表示しています。後でこのファイルを差し替えるか、`contactImage.src` を変更してください。サイズが変わる場合は `width`・`height`・`alt` も更新します。

フォームはメール作成用で、サーバーから自動送信しません。お名前・メールアドレス・相談内容と確認チェックを入力し、「内容を確認する」でプレビューを表示します。「メールアプリで送る」から宛先 `cbnbc07@gmail.com` のメールを開き、利用者が送信します。コピーにも対応しています。入力内容は保存されません。

主要な直接問い合わせリンクは `lib/site.ts` の `contactUrl`、またはビルド前の `NEXT_PUBLIC_CONTACT_URL` で変更できます。フォームの宛先・本文は `components/portfolio.tsx` で変更します。自動送信を導入する場合は別途サーバー側の送信処理・サービス設定が必要です。

## 4枚のブランドヒーロー

`public/images/heroes/` の先頭には、アップロードされた画像をそのまま使った `ai-first-view.webp`（1774×887）を表示します。元PNGと同じ画素の可逆圧縮WebPです。残り3枚には1920×640の `-natural` 版を使用します。ヒーローの表示枠は2:1で固定し、画像全体を切り取らず表示するため、切り替え時にページが上下しません。

- `ai-first-view.webp`：アップロード画像「AIとともに、もっと速く、もっと良いものを。」。男性2人と2体のロボット
- `brothers-natural.webp`：男性2人と2体。ホワイトボードとMacBookでの作業
- `couple-one-natural.webp`：最初のカップルと2体。ワイヤーフレーム確認とコーヒーの受け渡し
- `couple-two-natural.webp`：別のカップルと2体。iPhoneのテストと付箋でのストーリーボード整理

組み込みImageGenで元の人物・ロボットのイメージを維持しつつ、自然光と生活感のある制作スタジオへ編集しました。MacBook、iPhone、控えめなPrada・Loewe・Miu Miuなどの服飾ロゴを描いた制作イメージです。各ロボットに異なる作業・ポーズを割り当てています。編集プロンプトは `public/images/heroes/natural-prompts.json`。以前のブランド版と `prompts.json` も残しています。これらのブランドとの提携を示すものではありません。

4枚を常時マウントし、4秒間隔で850msのクロスフェードと穏やかな拡大・移動を行います。最初の画像はプリロード、残りはeagerで読み込みます。画像上に見出しや追加のロボットを重ねず、全景を表示します。停止・再生、タブ・矢印キー・Home・Endでの手動切り替えに対応し、キーボード操作中やreduced-motion設定時は自動切り替えを停止します。

スキル紹介は参考画像に合わせ、薄いグレーの図解エリアに白いカプセル型の3ステップを配置した3列のカードです。スマートフォンでは1列になります。カードは関連するパッケージのカテゴリへつながります。下のスキル紹介では、Yoom（https://lp.yoom.fun/）を参考に、2重のリングが80秒で回転し、技術名の丸いバッジは逆回転して正立を保ちます。停止・再生ボタンと `prefers-reduced-motion` に対応しています。表示は利用技術の例であり、アプリ連携機能の実装を示すものではありません。

パッケージ・ポートフォリオのカードも、ホバーまたは内部ボタンへのキーボードフォーカスで7色の発光枠と外周グローがアニメーションします。光のレイヤーはクリックを遮りません。動きを抑える設定では、浮き上がりと光のアニメーションを停止します。

## ボットモデル

アップロードされた4種類のモデルをもとに、背景を透過したWebP画像を `public/images/bots/` に配置しています。`sunset.webp`（暖色）、`peach.webp`（ハート）、`ocean.webp`（青）、`mint.webp`（緑）です。

各セクションの見出し、ヒーロー、ヘッダーのCTA、フッターに共通コンポーネントで表示します。装飾として扱うため、読み上げやクリック操作を妨げません。スマートフォンではサイズを抑え、ヘッダー内の画像は非表示にします。

画像は組み込みImageGenで元画像を編集したものです。共通指示：対象のロボット1体だけを使い、デザイン・素材・色・髪形・表情・ポーズを維持。チェッカー背景と隅のUIマークを除去し、全身が切れない5%の余白と本物の透過アルファを持つWeb用カットアウトにする。4つの対象は順に「暖色の髪で座って手を振る」「桃色でハートを持つ」「青・紫の髪で座って手を振る」「ミント色で人差し指を上げる」です。

## 開発・検証

Node.js 20.9以上が必要です。Windowsでは次のコマンドを使えます。

```powershell
npm.cmd ci
npm.cmd run dev
npm.cmd run typecheck
npm.cmd run build
```

開発サーバーは空いているポート（通常3000）で起動します。本番確認はビルド後に `npm.cmd run start`。

```powershell
npm.cmd run test:e2e
```

PlaywrightのテストはPC・モバイルの2構成です。セクション順序、全サンプルへのページ切り替え、検索・フィルタ、詳細・相談導線、FAQ、フォーム検証、メール本文、キーボード操作、reduced-motionを確認します。`CHROMIUM_PATH` に環境のChromium実行ファイルを指定してください（既定は `/usr/bin/chromium`）。ブラウザがない環境ではUIテストを実行できません。

## 公開

VercelなどNext.js対応ホスティングにデプロイできます。ビルドは `npm run build`。現在のサイトに外部APIキーやデータベースは不要です。
