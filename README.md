# 大穂兄弟 / OHO BROTHERS

ホスト版：[大穂兄弟](https://oho-brothers-portfolio.h6wtz8mqjg.chatgpt.site)（一般公開・サインイン不要）。公開状況と更新手順は [ホスティングの記録](docs/deployment.md) を参照してください。

日本語の制作ポートフォリオ。Next.js 16.4.3 / React 19.3.1 / TypeScript。

画面の見出し・本文・項目名・サンプル名・代替テキスト・共有画像・エラーページは日本語に統一しています。技術名と連絡先はロゴ・マークで示し、問い合わせ先の識別子は画面に表示しません。実際のメール宛先・外部リンク・コピーするユーザー名は `lib/site.ts` に保持します。

連絡先は４つのアイコンを並べたパネルです。メール・チャットワーク・テレグラムは窓口へのリンク、ディスコードはユーザー名のコピーです。カテゴリボタンは中央揃えで、右上に所属件数を表示します。押せる操作には軽い段差と押し込みの表現を付けています。元の鮮やかな７色ホバーは維持しています。

配色・文字組の参考は [国内の制作事例](https://sankoudesign.com/)、[２０２６年の国内デザイン解説](https://sinmido.com/news/p6793/)、[デジタル庁の日本語文字組](https://design.digital.go.jp/dads/foundations/typography/) です。白と余白、墨に近い文字、藍色の限定的なアクセントを採用しています。特定の配色が日本全体で最も人気であることを示すものではありません。

ブランドの約束・キャラクターの役割・公開前に必要な実情報は [ブランド運用ガイド](docs/brand-guide.md) にまとめています。

## 開発とプレビュー

```powershell
npm.cmd ci
npm.cmd run dev -- --port 3001
npm.cmd run typecheck
npm.cmd run build
npm.cmd run start -- --port 3001
```

プレビューは http://localhost:3001 。開発サーバーと本番サーバーを同時に同じポートで起動しないでください。ビルド時は開発サーバーを止め、本番確認用に起動し直してください。

## ページとデザイン

1. 「デザインと開発を、ひとつのチームで。」の約束と、4秒で切り替わるブランドシーン。
2. 商品絞り込み・タスク管理・日記追加を試せる3つの自主制作デモ、担当と経験を確認できる常時表示のプロフィール。
3. Webサイト・業務システム・継続改善の3つの入口。対応領域・ワークフロー・技術リングは展開して確認。
4. 相談から引き継ぎまでの4段階と、各段階で確認すること。
5. 提供資料に基づく20件のパッケージ。カテゴリ絞り込み・6件ずつのページ切り替え・税別プラン比較・詳細。
6. 30件の架空ポートフォリオ。検索・カテゴリ・9件ずつのページ切り替え・コンセプト詳細。
7. 8つのFAQとボットガイド。
8. 連絡先とフォーム。PCは横並び、760px以下は縦並び。
9. ページの白から淡い青灰色へなじむフッター。縦書きの屋号、用途がわかるリンク、ページ先頭への操作。

色・文字・余白・カード・ボタンは **`app/site.css` の1か所**で管理します。旧テーマ10枚の重複ルールと未使用セレクタは削除しました。クールなライトグレー、白いカード、スレートの本文、インディゴの案内・相談ボタン、ページの白から淡い青灰色へなじむフッターを組み合わせています。画像は元の彩度を保ち、ホバーは赤・橙・黄・緑・青・藍・紫の鮮やかな7色グローを使用します。`--paper`、`--surface`、`--ink`、`--muted`、`--accent`、`--cta` が配色の共通トークンです。Noto Sans JPとDM Sansはローカル配信です。

パッケージ・制作例・サービス・ワークフローの7色グローは、ホバーとキーボードフォーカスで鮮やかに発光します。タッチ端末でホバーが残る影響を抑え、reduced-motionでは回転・光・切り替えアニメーションを止めます。ヒーローとスキルリングは画面外で停止します。

主なファイル：

- `components/portfolio.tsx`：ページ構成、ナビゲーション、検索・フィルタ・ページ切り替え、詳細ダイアログ。
- `components/hero-showcase.tsx`：固定H1、4秒のブランドシーン切り替え、停止・再生、矢印・Home・End操作。AOとIROのキャラクターとHTMLで描く図解です。
- `components/brand-story.tsx`：兄弟のストーリー、3つのサービス入口、4段階の進め方、問い合わせ後の案内。
- `components/concept-demo.tsx`：mori. / flow / 日々、の操作できるデモ。画面内の状態のみ使用し、保存しません。
- `components/brother-introductions.tsx`：専門性、経験、ボットの吹き出し。
- `components/skill-workflows.tsx`：ワークフローカードと80秒周期のリング。バッジは略号ではなく技術名を表示し、静的な技術一覧も併記。
- `components/faq-section.tsx`：短い質問と回答。送信方式に応じて説明が変わります。
- `components/contact-methods.tsx`：窓口別のカラーアイコンとコピー。コピー状態は3秒後に解除。
- `components/contact-form.tsx`：入力検証、送信・確認・コピー、エラー時の入力保持。
- `components/pattern-footer.tsx`：屋号とラベル付きのリンク。
- `lib/service-packages.ts`：提供された20件の資料に基づくサービス、税別料金、プラン別範囲、条件、出典ファイル・料金ページ。
- `components/package-plan-details.tsx`：プラン比較、単体制作メニュー、費用・納期の案内。
- `lib/catalog.ts`：カテゴリと架空の制作コンセプト。
- `docs/package-sources.md`：パッケージ情報の出典と更新方針。
- `lib/site.ts`：公開連絡先と差し替え用の案内画像。
- `app/opengraph-image.tsx`：1200×630の共有画像。

表示件数とページ数はデータから計算します。フィルタ・検索・ページはURLの `package`、`work`、`q`、`pp`、`wp` に保存され、再読み込み後も復元します。メニューとダイアログはフォーカスを管理し、背景をinertにし、Escapeで閉じられます。

## ブラウザ検証

```powershell
npm.cmd run test:e2e
node scripts/capture-review.cjs
```

PlaywrightはPC（1440×1000）とモバイル（iPhone 13相当）で確認します。Windowsではインストール済みChromeを自動選択します。他環境ではPlaywrightのブラウザ、または `CHROMIUM_PATH` を指定してください。ベースURLは `http://localhost:3001`、変更時は `PLAYWRIGHT_BASE_URL` を指定します。この環境では127.0.0.1経由で開発用接続が正常に動かないため、表示されたlocalhostのURLを使います。

画面キャプチャは `test-results/review/`（Git対象外）。ナビゲーション、全20/30件への到達、詳細・相談、FAQ、フォーム、コピー、4秒の切り替え、キーボード、reduced-motion、URL復元をテストします。直接送信のテストはプロバイダAPIをモックし、実メールを送信しません。

オレンジの案内ボットには、手を差し出す紹介ポーズを使用します。元画像は維持し、生成方法・保存先・プロンプトは `docs/bot-pose.md` に記録しています。

## 今回の改善と公開準備

制作例に設計判断・制約・公開コードを追加しました。パッケージは資料の表紙画像、制作コンセプトは画面模型を使用します。兄弟の紹介とスキルのボット紹介は常時表示し、パッケージの二次情報は展開式にしています。基本価格の対象範囲と追加費用の条件を明示しています。ヒーローの停止操作はスライドと流星の両方に適用します。

操作計測は同一サイトの `/api/events` に接続しています。フォーム内容や個人識別子を含めず、サーバーログに構造化レコードを出力します。`npm.cmd run analytics:report -- path/to/server.log` で集計できます。計測とメール送信の設定、実績資料に関する残作業は [公開準備の記録](docs/launch-readiness.md) を参照してください。

パッケージには提供資料の表紙画像を再表示しています。兄弟の紹介はストーリー・大型キャラクター・吹き出しを含む元の構成です。ボットによるスキル紹介は、折りたたみの外に配置し、画面内で自動的に動きます。停止操作と動きを抑える設定は維持します。
