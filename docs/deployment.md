# ホスティング

配信先： https://oho-brothers-portfolio.h6wtz8mqjg.chatgpt.site

Sites 上でデプロイ済みです。利用者の明示的な承認に基づき、公開範囲を一般公開へ変更しました。リンクを知っている方はサインインせず閲覧できます。正確なプロジェクト・バージョン・デプロイ識別子は `deployment.json` に記録しています。

## ソースと実行環境

- このリポジトリは従来どおり Next.js のローカル開発用です。
- ホスト用チェックアウトは `.deployment/portfolio`。Sites のスターターを利用し、既存の画面・画像・フォント・サーバールートを Vinext と Cloudflare Workers でビルドしています。
- ホスト用ソースは Sites のソースリポジトリに保存されています。生成物、依存パッケージ、Git の内部情報をこのリポジトリへ重複して追加しないため、`.deployment` を除外しています。
- ルートの型チェックからホスト用チェックアウトを除外しています。
- 画像の切り取りを防ぐ指定は、ホスティング環境でも確実に適用されるよう、画像コンポーネントへ明示しています。
- 表示・操作の四十二項目をホスト用実行環境で確認しました。最初の確認で見つかった画像サイズの二項目は修正後に再確認しています。
- 配信用のメール設定は未登録です。現状は既存のメールアプリへの引き継ぎを使用します。

## 更新する場合

GitHub へのコミットだけでは Sites の公開内容は更新されません。

1. `deployment.json` とホスト用チェックアウトの `.openai/hosting.json` で、同じプロジェクトを選びます。新しいサイトを作成しません。
2. `node scripts/prepare-hosted-source.cjs` で画面・画像の変更を既存チェックアウトへコピーします。
3. 依存関係を変更した場合はホスト用パッケージにも反映し、Sites の依存関係ヘルパーでインストールします。
4. Sites のソースヘルパーで最新の短期認証を使って開き、ビルド、確認、コミット・プッシュ、アーカイブ化を行います。認証トークンはファイルに保存しません。
5. 検証済みソースの保存版をデプロイし、成功を確認して `deployment.json` を更新します。現在の公開範囲を維持します。
