# 青いボットを主役にした配色とプロフィール

ユーザー指定の参考サイト `https://webmarks.co.jp/` を確認し、白・濃紺・青の強い対比を採用。青いボットのシアンと紫をアクセントにし、従来の４色を均等に使う構成から、青を中心にした明確な階層へ変更しました。

- 基本文字：`#07213c`
- 主な青：`#1061a7`、`#125ac1`
- 濃紺のセクション：`#061d3d`
- シアン：`#18bcec`
- 紫：`#703de0`
- 基本背景：`#f4f9ff`、カード：白と薄い青

ヒーローのボット背景、選択タブ、相談ボタン、作品デモ、進め方、問い合わせ、フッターに配色を適用。明朝見出し、筆文字ロゴ、背景写真とぼかし、７色のホバー、クリック後も続く演出を維持。参考サイトの名称・文章・画像は転用していません。

## 確認済みのプロフィール置き換え

ユーザーが「既存の兄弟紹介を置き換える」を選択したため、旧２人分の紹介カードと紹介文を、提供された経歴の日本語プロフィールに置き換えました。学歴、現在のアシスタント職、初期段階のプロジェクト支援、起業家の海外展開支援、コミュニティ運営、過去の所属、事業分析・財務モデリング・国際的な事業運営の経験を掲載。

氏名、在籍期間、役職、案件金額、資格、成果の数値は追加していません。旧紹介と整合しない11年・３年の表示や、兄弟での役割分担を個人経歴として語る文章は整理。サイトのブランド名・サービス・既存作品は維持しています。青いボットは紹介役として使い、本人の肖像とはしていません。

新しい日本語の文字に合わせ、既存の自己配信しっぽり明朝を再生成。画像生成は使用していません。
