# System-development project thumbnails

All 12 system-development portfolio entries now have distinct modern concept previews. The 1200 × 800 WebP images share navy navigation, white cards, soft blue-gray backgrounds, and project-specific accents. Each is visibly labeled as a concept preview and does not represent an actual client screen or implementation.

Images are saved under `public/images/portfolio/*-dashboard-v2.webp`. The original assets are retained. All images were made using the built-in ImageGen tool and optimized with Sharp. Exact asset paths and all 12 generation prompts are in [system-project-images.json](system-project-images.json).
