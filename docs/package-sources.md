# パッケージ情報の出典

2026年10月29日に提供された `C:\Users\hanar\Downloads\packages` 内の20件の資料を使用しています。公開データは `lib/service-packages.ts` で管理します。各レコードの `source` は元のファイル名、`pricingPage` は料金表のページ番号です。

## 掲載ルール

- 仮の20件を、提供資料にある20サービスへ置き換えました。料金はすべて税別です。
- 19サービスはベーシック・スタンダード・プレミアムの三段階。デザイン統一は、紹介ページ、ホームページ一ページ、バナー、ロゴの単体制作メニューです。
- デザインの紹介ページは三万〜十万円、ホームページは一ページ八千〜一万五千円、バナーとロゴは各三千円からです。カードの三千円は単体制作の最小価格であり、サイト一式の価格ではありません。
- 固定の納期は資料に記載されていないため、以前のランダムな期間を削除しました。要件と希望公開日を確認したうえで決定します。
- 運用月額は資料の概算です。実費・利用プラン・処理量・保守契約によって変動するため、契約時に内訳を確認する案内を添えています。
- サービス内容とプラン範囲は、読みやすい日本語で要約しています。検索順位、売上、審査結果、速度スコアなどの保証を新たに追加しません。
- 大規模プランのページ数・機能数・継続期間は個別見積もりで確認します。
- 元の資料はサイトへ複製していません。大容量の資料を初期表示で読み込むことはありません。
- ポートフォリオの30件は引き続き架空の制作コンセプトです。パッケージと混同しないよう、注意書きを分けています。

## 更新方法

`lib/service-packages.ts` の説明、各プランの料金・支援範囲、条件を更新してください。価格・範囲・出典を同時に確認し、カテゴリ件数・ページ切り替え・相談フォームは共通データから自動更新されます。新規サービスを追加する場合は、既存の識別子を変更せず一意の識別子を割り当ててください。

料金表は原則五ページ目、技術相談・一貫開発のみ六ページ目です。デザイン、通販サイト、技術相談の料金表は画像としても確認しています。
