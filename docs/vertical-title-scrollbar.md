# 縦書きの筆文字と読書用スクロールバー

ヒーロー左側の主見出し「デザインと開発を、ひとつのチームで。」を縦書きの筆文字に変更しました。画像化せず、通常の見出しテキストとして選択・拡大・読み上げができます。紹介文と相談ボタンは隣に配置しています。

書体は Google Fonts が提供する Yuji Boku。主見出しの文字を含む小さなサブセットを `public/fonts/yuji-boku-title.ttf` に保存し、ローカル配信します。ライセンス全文は `public/fonts/yuji-boku-OFL.txt`。出典：https://github.com/google/fonts/tree/main/ofl/yujiboku 。

ページ本文に干渉しない独立した読書用レールを追加しました。広い画面では右側の縦型、狭い画面では下部の横型です。多角形のしおり型つまみ、進み具合、先頭・末尾への操作を備え、通常のブラウザのスクロールバーも使えます。

レールのクリック・ドラッグに加え、矢印、ページアップ・ページダウン、ホーム・エンドに対応。読み上げ用のスクロールバーの役割・方向・現在位置を提供します。ウィンドウサイズや本文の高さが変わると表示を更新し、動きを減らす設定ではボタンでの移動を即時にします。操作位置の外部送信や保存は行いません。

主な実装：`components/page-scrollbar.tsx`、`app/layout.tsx`、`app/site.css`。確認：`tests/hero-scrollbar.spec.ts`。
