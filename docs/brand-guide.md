# 大穂兄弟 / OHO BROTHERS — ブランド運用ガイド

## 約束と対象

主な対象は中小企業・小さなチーム。Webサイトと業務システムを、デザイン・開発のひとつの窓口で相談できる制作チームとして紹介します。

メインメッセージ：**デザインと開発を、ひとつのチームで。**

「考える兄と、描く弟。」はチームを覚えてもらうための紹介文です。AIは手段のひとつとして扱い、すべての相談をAI検索対策として見せません。

## 表記・声・見た目

セクションの背景は、導入のアイスブルー、制作デモのラベンダー、兄弟紹介の青みグレー、サービスのセージ、進め方の淡い砂色、パッケージのペールブルー、制作コンセプトのローズ、質問のミント、問い合わせの青灰色で変化をつけます。各背景の上下は共通の紙色へ戻し、境界が強い帯にならないようにします。カードは白を保ち、文字と操作の色は既存の濃色を維持します。

制作イメージは、ラベンダーとアプリコット、ミントとイエロー、コーラルとライラックなどを組み合わせた小さな画面模型で表現します。サービスの三つの入口は紫・緑・珊瑚色、制作の四段階は紫・青緑・琥珀色・ローズで区別します。色のほかに見出し・番号・アイコンを必ず併記し、本文と操作ボタンは濃色で読みやすさを保ちます。既存の七色ホバーは維持します。

- 公開画面では「大穂兄弟」と日本語の説明を使います。旧英語表記は内部の資料に限り、見出し・項目・本文に英字ラベルを追加しません。個人名・読み仮名は確認前に推測しません。
- 具体的な課題と進め方を、短く平易に説明します。成果保証・架空の顧客・未測定の改善率は掲載しません。
- 白い面、墨に近い文字、青・藍色、濃紺が基本色。既存の鮮やかな7色ホバーはブランドの操作表現として維持します。押せる操作には小さな段差と押し込みを付けます。
- ボットは案内役。人物本人の代わりの肖像、スタッフ数の証拠、実在顧客として扱いません。
- ヒーローの１枚目は既存のキャラクター図解を保ち、２〜４枚目は人が判断と作業を主導する制作イメージです。ボットは材料・発想を補助します。
- 連絡先は日本語名を添えたプラットフォームのアイコンで表示し、メールアドレスや識別子を画面には並べません。技術の回転リングも文字の略号ではなくマークを使います。
- パッケージ・制作例のカテゴリボタンは中央に並べ、右上のバッジに元データの所属件数を表示します。

## 提供内容と見せる順序

約束 → 3つの操作デモ → 兄弟と考え方 → 3つのサービス → 進め方 → 詳細カタログ → FAQ → 問い合わせ。

サービス入口は、Webサイト、業務システム、公開後の改善。技術の一覧は補足として展開表示します。費用・納期・修正範囲・外部サービス費・公開後の保守は、個別の提案で確認する項目です。提供された資料の税別プラン料金を掲載します。プラン内の具体的な作業量や実費、保守範囲、費用・納期は個別見積もりで確認します。

3つの自主制作デモは実装済みの画面操作を示します。クライアント実績ではありません。ケース紹介では「課題」「実装した操作」「設計意図」「確認できること」を区別します。架空の成果数値を追加しません。

## 問い合わせと測定

直接送信には `.env.example` のResend設定と認証済み送信元が必要です。設定のない環境では、メールアプリへの引き継ぎを明示します。返信時間は確定前に約束しません。

`lib/interaction-events.ts` はブラウザ内の通知に加えて、同一サイトの `/api/events` に接続します。操作名と許可済みのカテゴリ・カタログ識別子だけを扱い、本文・氏名・メール・検索語は送信しません。追跡拒否設定に従います。サーバーログの保存と集計方法、メールを開いた操作と送信完了の区別は `docs/launch-readiness.md` を参照してください。
