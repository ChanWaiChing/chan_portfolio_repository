# 静かな和の読み心地

ページ左端に、本文と同じグリッドに属する読書用レールを配置。デスクトップも携帯画面も縦方向のまま、ドラッグ・位置指定・キーボード・先頭／末尾ボタンで操作できます。ブラウザー標準のスクロールも利用できます。

各主要セクションの見出しは左に縦組みで配置。章の説明とカードは右の本文領域にそろえています。本文の最大幅を従来より広げ、パッケージと実績のデスクトップ４列を維持しました。携帯画面では余白と文字サイズを調整しています。

背景を連続する中庭写真に統一し、各章の不透明な背景の切れ目を解消。写真上には読みやすさのための灰緑色の透過レイヤーを設置。フッターの既存画像は変更せず、左右に余白と角丸を追加しました。７色ホバー、流星カーソル、章ごとの登場アニメーションと停止操作を維持しています。
