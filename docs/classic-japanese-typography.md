# 大きく、読みやすい和の見出し

サイトの主見出し・小見出し・紹介ラベルを、しっぽり明朝の太めのウェイトに統一。セクション見出しはデスクトップで最大48ピクセル、携帯画面で29〜36ピクセル。カードは用途に応じて19〜32ピクセル、補助見出しは15〜17ピクセルに拡大しました。

対象：ヒーロー、各章、兄弟紹介、サービス、技術紹介、制作の進め方、パッケージ、実績、質問、問い合わせ、フッター、詳細ダイアログ、自主制作デモの見出し。本文やフォーム入力欄は読み慣れた書体を維持し、直前に作成したロゴの筆文字も保持しています。

大きい文字が窮屈にならないよう、サービスの見出しサイズとヒーロー画像領域を調整。カテゴリーの演出継続、明示的停止、動きを減らす設定を維持。

## フォント

- `public/fonts/shippori-mincho-headings.ttf`：しっぽり明朝、ウェイト600。現在のコンポーネントとデータで使用する日本語684文字と基本英数字の自己配信サブセット。
- `public/fonts/shippori-mincho-OFL.txt`：SIL Open Font License。
- `scripts/prepare-heading-font.cjs`：文字集合と配信ファイルを更新するスクリプト。新しい見出しを追加した際は再実行可能。
- 配布元：Google FontsのShippori Mincho、ライセンス元はGoogle Fontsの公式リポジトリ。

画像生成は使用していません。見出しは画像化せず実テキストとして保持しています。

## 検証

ビルド、すべての見出しの書体、文字サイズ、フォント読み込み、320〜1440ピクセルの収まり、詳細ダイアログ、ロゴ、ヒーローの自動切り替え・停止をデスクトップ／携帯ブラウザーで確認。
