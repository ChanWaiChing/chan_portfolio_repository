# アイコンの出典

技術・サービスのマークは Simple Icons の公開SVGを必要分だけ同梱しています。

- 出典: https://github.com/simple-icons/simple-icons
- 配布ライセンス: CC0-1.0
- 対象: Discord、Telegram、Python、WordPress、Figma、React、Next.js、TypeScript、Node.js、Android、Apple、Git
- `components/brand-icons.tsx` にパスを同梱し、外部通信なしで表示します。
- メール・連携・人工知能・画面設計の図形は既存の Lucide アイコンを使用します。
- チャットワークは公式サイトの [ロゴ素材](https://go.chatwork.com/ja/image/common/cw_logo_hz_color.svg) からシンボル部分のみを使用しています。英字のワードマーク部分は表示しません。

各社の商標はサービス・技術を識別するための表示であり、提携を示しません。
