# 公開と計測の確認

## お問い合わせ

サーバー側の直接送信は既存の `/api/contact` を使用します。`RESEND_API_KEY` と、検証済みドメインのアドレスを使う `CONTACT_FROM` をサーバーの環境変数に設定すると有効になります。鍵はブラウザへ渡しません。返信先は入力されたアドレス、受信先は固定の窓口です。送信失敗時は入力を残し、メールアプリとコピー操作へ案内します。

2026年10月29日の確認時点で、このチェックアウトには設定済みの鍵がなく、接続済みメールアカウントには検証済みドメインがありません。したがって直接送信を有効と見せかけず、メールアプリを一回の操作で開く方式を提供します。実際の送信はメールアプリで行います。フォーム送信の動作はモックで検証し、実メールによる疎通は未実施です。

## 制作例と経験の根拠

公開している三つの自主制作デモに、操作・設計判断・制約と公開コードへのリンクを追加しています。クライアント名、納品実績、売上などの成果は新たに作成していません。実案件を追加する場合は、公開許可のある画像、担当範囲、期間、確認可能な成果を準備してください。プロフィールの経験年数は従来の掲載値です。

## 価格と条件

資料の税別価格を維持し、カードに最小価格の対象と基本範囲を表示します。修正回数、作業量、追加機能、外部サービスの実費、運用・保守は見積もり時に確認します。資料にない固定回数や期間は設定しません。全サービス共通の月額金額は総額を誤認しやすいため、運用環境・保守範囲による別途見積もりの表示にしています。

## 操作の計測

`lib/interaction-events.ts` から同一サイトの `/api/events` へ操作名と、該当する場合のみパッケージ・制作例の識別子やカテゴリを送ります。問い合わせ文、メール、氏名、ページの検索語、個人識別子、利用者の生の参照元は送信しません。追跡拒否設定に従い、独自のクッキーや閲覧者識別子を作成しません。

サーバーログには `site_interaction` の構造化レコードが出力されます。公開環境でログ保存を有効にし、ログを取得して以下で日別・操作別・対象別に集計できます。

```powershell
npm.cmd run analytics:report -- path/to/server.log
```

確認できる操作は相談開始、相談導線、メール作成・アプリを開く操作、メール送信サービスの受付、失敗、パッケージ詳細、制作例、サービスカテゴリです。メールアプリを開いた件数は送信完了件数ではありません。サービス受付も受信箱への配達保証ではありません。外部の解析サービスやダッシュボードは接続していません。ログの保存期間・権限・ローテーションは公開環境で設定してください。基盤標準のアクセスログは別途管理されます。

## 表示

カードの図は同じ色・余白のルールを使う軽量な画面模型に統一しています。元資料の画像は保持しています。チーム紹介と二次情報は展開表示にし、制作例の図は固定の座標系で縮小するため端末幅で文字や図が切れません。ヒーローの停止操作はスライドと流星の両方に適用します。七色ホバーと動きを抑える設定は維持しています。
