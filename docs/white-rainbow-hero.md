# 白いファーストビューと虹色の見出し

## 画面の変更

- ヒーローの左右の大きな外枠・背景・影を取り除き、白い画面に統一。画像の周囲の大きなパネルも削除しました。
- 縦組み見出しは、既存の自己配信Noto Sans JP Variableの900ウェイトへ変更。７色のグラデーションと、文字の内側をゆっくり移動する淡い光、柔らかな光彩を重ねています。文字は画像化せず実テキストを維持。
- ２つの相談・制作例ボタンは中央配置。携帯画面では見出しと説明の下に幅いっぱいの行を設け、ボタンの文章に余裕を確保。
- 右側の画像説明は、太めの現代的なゴシック体と中央揃えへ変更。
- ４つの画像切り替えは「チーム紹介」「企画・戦略」「デザイン・開発」「運用・改善」に整理。番号の前にアオ・トモ・イロ・ループを１体ずつ配置し、それぞれ異なる見た目の既存素材を使用。選択中の項目には４秒の進行ラインを表示。
- 右下のヒーロー専用の停止・再生ボタンを削除。画面左下の演出操作へ統合し、虹色の光・画像の自動切り替え・スキル演出をまとめて停止可能にしました。画像にフォーカスした状態でスペースキーによる切り替えも利用できます。
- 本文・見出し・補助文字・ボタン・フォームなど、ページ全体の文字を拡大。その他の章の明朝見出しとブランドロゴは維持。

## 書体

[Google FontsのNoto Sans JP公式メタデータ](https://github.com/google/fonts/blob/main/ofl/notosansjp/METADATA.pb)で日本語対応とウェイト900を確認。日本全体の人気順位は断定せず、現代的な字形・日本語の収録範囲・太さの選択肢を理由に採用しました。既存の `@fontsource-variable/noto-sans-jp` を利用し、新しいフォント配信元は追加していません。

## 動きと読みやすさ

虹色の文字は白背景で読める深い色を基本にし、光彩は抑えています。動きを減らす設定では、光の移動と自動切り替えを停止。画像切り替えはクリック後も継続し、利用者が演出停止を選んだ場合は再生しません。４つのタブの矢印・先頭・末尾キー操作を維持。

## 検証

デスクトップ・携帯画面で、白い背景、太い縦文字、虹色の描画、中央揃え、４体の素材、不要な停止ボタンの削除、全体の停止・再開、画像切り替え、フォームとカタログ、320〜1440ピクセルの表示を確認。
