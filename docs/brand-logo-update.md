# ロゴとカテゴリー演出

ヘッダーのロゴを、藍色の印の上で２本の筆線が重なるシンボルに更新。技術とデザインの２つの視点がひとつのチームになることを表現しています。青紫とミント、淡い橙と桃色は既存のボットの配色に合わせました。ファビコンにも同じシンボルを使用。

「大穂兄弟」「デザインと開発」はYuji Bokuの筆文字に変更。`public/fonts/yuji-boku-brand.ttf` は使用文字のみの自己配信サブセット。既存の `public/fonts/yuji-boku-OFL.txt` にあるSIL Open Font Licenseを維持。ブランド文字のフォントを事前読み込みし、SVGシンボルと実テキストを組み合わせています。画像生成は使用していません。

カテゴリーのクリック・フォーカス・矢印キー操作では自動切り替えと流星ボーダーを停止しません。選択した画像は４秒間表示してから次へ進みます。明示的な停止ボタン、動きを減らす利用者設定、画面外での停止を維持。停止ボタンで止めたあとにカテゴリーを選んでも、勝手に再生しません。

デスクトップと携帯画面で、クリック後の演出継続、４秒ごとの切り替え、明示的停止、筆文字フォントの読み込み、320〜1440ピクセルのヘッダー表示を検証。
